# E-commerce_sales_excel_dashboard

## Project overview:
Developed an interactive Ecommerce sales analysis dashboard using Microsoft excel to analyze sales performance, profitability, product categories and Year-over-Year (YoY) Growth. The dashboard provides a consolidated view of key business metrics to support data-driven decision making.

## Objectives:
* Analyze overall sales, profit, quantity sold and order volume.
* Evaluate sales and profit trends across months and years.
* Compare profitability across product categories.
* Identify top performing product sub categories by sales.
* Analyze geographic sales performance across US states.
* Track Year-over-Year changes in key performance indicators (KPIs).

## Tools and Techniques:
* **Microsoft Excel**
* PivotTables and PivotCharts
* Slicers for interactive filtering
* Waterfall, Combo, Donut, column and map charts
* Conditional formatting and KPI indicators
* Excel formulas and percentage growth calculations

## Key dashboard features:
* **KPI cards**: Display total sales, total profit, quantity sold, order count and profit margin.
* **Sales and profit analysis**: Visualizes monthly sales and profit trends.
* **Category wise profitability**: Compares profits across product categories.
* **Sales distribution**: Shows each category's contribution to total sales.
* **Geagraphic analysis**: Visualizes sales performance across US states.
* **Top 5 sub-categories**: Highlights the leading sub categories by sales.
* **Interactive filters**: Enables dynamic analysis by year, customer segment and region.
* **YoY Growth tracking**: Displays year-over-year percentage changes using visual indicators.

## Business value:
The dashboard brings multiple sales metrics into one interactive view, making it easier to explore performance trends, compare product categories, identify high performing products and regions, monitor changes in business KPIs.
